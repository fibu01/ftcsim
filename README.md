# ftcsim

Browser-based 3D FTC robot simulator for the BIOBUZZ 2026-27 season. Three.js, Rapier, Vite, TypeScript. Students paste a Java TeleOp, run it against a mecanum robot on a 3D field, inject faults, and replay runs.

Live build: https://fibu01.github.io/ftcsim/ (every push to main redeploys).

See `docs/PRD.md` for scope and `docs/reference-projects.md` for sources.
